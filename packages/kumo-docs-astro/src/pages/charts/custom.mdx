## 自定义 HTML Tooltip

对于需要自定义 HTML 格式的 tooltip，请使用 `dangerousHtmlFormatter` 属性，而不是标准的 `formatter`。这样安全影响会更加明确。

使用 `dangerousHtmlFormatter` 时，**强烈建议**使用 `echarts.format.encodeHTML` 对任何用户提供的内容进行净化，以防 XSS 漏洞。
