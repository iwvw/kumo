## 用法

```tsx
import { Popover, Button } from "@cloudflare/kumo";

export default function Example() {
  return (
    <Popover.Root>
      <Popover.Trigger render={<Button />}>Open</Popover.Trigger>
      <Popover.Portal>
        <Popover.Positioner>
          <Popover.Popup>
            <Popover.Arrow />
            <Popover.Title>Popover Title</Popover.Title>
            <Popover.Description>Popover content goes here.</Popover.Description>
          </Popover.Popup>
        </Popover.Positioner>
      </Popover.Portal>
    </Popover.Root>
  );
}
```

    Popover 虽然可以配置为悬停触发（使用 `openOnHover`），但它与

### 已弃用的 Content 兼容性

<p>
  `Popover.Content` 已弃用，但仍保留可用，以确保现有的 Popover
  不会失效。它将 `Portal`、`Positioner`、`Popup` 和 `Arrow`
  组合为一个组件，并且仅使用透明度平滑淡入，不带缩放或
  变换动画。新的 Popover 应按照基础示例所示
  组合各个独立部分。
</p>
<ComponentExample demo="PopoverLegacyContentDemo">
  <PopoverLegacyContentDemo client:load />
</ComponentExample>

### 可滚动内容

<p>
  当箭头和标题需要保持固定时，请将溢出的内容放入
  内部滚动容器中。已弃用的 `Popover.Content`
  上现有的溢出样式仍由其仅淡入的过渡所支持。
</p>

### 悬停打开

<p>
  在触发器上使用 `openOnHover`，即可在用户悬停时打开 Popover。
  还可以通过 `delay` 指定 Popover 出现前的毫秒延迟。
</p>
<ComponentExample demo="PopoverOpenOnHoverDemo">

### 虚拟锚点

<p>
  在 `Popover.Positioner` 上使用 `anchor` 属性，将 Popover 定位到触发元素以外的其他
  元素上，或定位到某个虚拟点（例如 `getBoundingClientRect()` 返回的
  `DOMRect`）。当触发器与期望的锚点位于不同的组件树中时，
  这会非常有用。
</p>

## API 参考

### Popover.Root

<p>负责管理 Popover 打开状态的基础组件。</p>
<PropsTable component="Popover" />

### Popover.Trigger

<p>
  点击时打开 Popover 的按钮。使用 `render`
  渲染你自己的元素。
</p>
<PropsTable component="Popover.Trigger" />

### Popover.Portal

<p>
  在应用的 DOM 层级之外渲染 Popover。它默认使用来自
  `KumoPortalProvider` 的容器，并接受 `container` 属性
  来覆盖该容器。
</p>
<PropsTable component="Popover.Portal" />

### Popover.Backdrop

<p>一个可选背景遮罩，渲染在 Popover 后方。</p>
<PropsTable component="Popover.Backdrop" />

### Popover.Positioner

<p>
  将弹出层相对于其触发元素或某个 `anchor` 定位。使用 `side`、
  `align` 及其偏移属性来控制放置位置。
</p>
<PropsTable component="Popover.Positioner" />

### Popover.Popup

<p>
  带样式的弹出层容器。将 `Popover.Arrow` 和 Popover 内容
  直接放在其中。
</p>
<PropsTable component="Popover.Popup" />

### Popover.Arrow

<p>一个可选箭头，指向 Popover 的锚点。</p>
<PropsTable component="Popover.Arrow" />

### Popover.Viewport

<p>
  用于在多个触发元素共用一个弹出层时，为内容变化添加动画的视口。
  普通的 Popover 或可滚动内容并不需要它。
</p>
<PropsTable component="Popover.Viewport" />

### Popover.Content

<p>
  一个已弃用的兼容包装组件，组合了 `Portal`、`Positioner`、
  `Popup` 和 `Arrow`。现有用法仍受支持，但新代码应
  组合上文所示的各个独立部分。
</p>
<PropsTable component="Popover.Content" />

### Popover.Title

<p>为 Popover 提供无障碍标签的标题。</p>
<PropsTable component="Popover.Title" />

### Popover.Description

<p>提供关于 Popover 内容补充信息的段落。</p>
<PropsTable component="Popover.Description" />

### Popover.Close

<p>
  点击时关闭 Popover 的按钮。使用 `render`
  渲染你自己的元素。
</p>
<PropsTable component="Popover.Close" />
