## 用法

```tsx
import { Popover, Button } from "@cloudflare/kumo";

export default function Example() {
  return (
    <Popover>
      <Popover.Trigger render={<Button />}>Open</Popover.Trigger>
      <Popover.Content>
        <Popover.Title>Popover Title</Popover.Title>
        <Popover.Description>Popover content goes here.</Popover.Description>
      </Popover.Content>
    </Popover>
  );
}
```

## Popover 与 Tooltip 的对比

  <p>
    Popover 虽然可以配置为悬停触发（使用 `openOnHover`），但它与
    Tooltip 的用途不同。理解何时使用两者，对于可访问性
    和用户体验都很重要。
  </p>
  <div class="overflow-hidden rounded-lg border border-kumo-hairline">

          <th class="px-4 py-3 text-left font-semibold">Popover</th>
        </tr>
      </thead>
      <tbody class="divide-y divide-kumo-hairline">
        <tr>
          <td class="px-4 py-3 font-medium">用途</td>
          <td class="px-4 py-3 text-kumo-subtle">
            简短、不可交互的文字标签，用于内容标识
          </td>
          <td class="px-4 py-3 text-kumo-subtle">
            丰富、可交互的内容容器
          </td>
        </tr>
        <tr>
          <td class="px-4 py-3 font-medium">内容</td>
          <td class="px-4 py-3 text-kumo-subtle">仅限纯文本</td>

  <p>
    当你需要给图标按钮加标签或提供简短说明时，使用 <strong>Tooltip</strong>。
    当用户需要与其中的内容交互时——例如点击链接、
    填写表单或用按钮关闭——则使用
    <strong>Popover</strong>。
  </p>

### 虚拟锚点

<p>
  在 `Popover.Content` 上使用 `anchor` 属性，将 Popover 定位到触发元素以外的其他
  元素上，或定位到某个虚拟点（例如 `getBoundingClientRect()` 返回的
  `DOMRect`）。当触发器与期望的锚点位于不同的组件树中时，
  这会非常有用。
</p>

### Popover.Trigger

  点击时打开 Popover 的按钮。使用 `render`

</p>
<PropsTable component="Popover.Trigger" />

### Popover.Content

<p>
  用于承载 Popover 内容的容器。通过 `side`、`align`、`sideOffset` 和
  `alignOffset` 属性控制定位。使用 `anchor` 属性可定位到自定义元素或虚拟点，
  而不是触发器。当 Popover 需要脱离层叠上下文
  （例如位于粘性头部内部）时，使用
  `positionMethod="fixed"`。
</p>
<PropsTable component="Popover.Content" />
