## 用法

### 使用内置 Field（推荐）

<p>
  为 InputGroup 传入 `label` 属性以启用内置 Field 包装器，支持标签、描述和错误提示。
</p>

```tsx
import { InputGroup } from "@cloudflare/kumo";
import { MagnifyingGlassIcon } from "@phosphor-icons/react";

export default function Example() {
  return (
    <InputGroup label="Search" description="Find pages, components, and more">
      <InputGroup.Addon>
        <MagnifyingGlassIcon />
      </InputGroup.Addon>
      <InputGroup.Input placeholder="Search..." />
    </InputGroup>
  );
}
```

### 裸 InputGroup（自定义布局）

<p>
  对于自定义表单布局，可在不带 `label` 的情况下使用 InputGroup，但必须在
  `InputGroup.Input` 上提供 `aria-label` 以保证无障碍访问。
</p>

```tsx
import { InputGroup } from "@cloudflare/kumo";
import { MagnifyingGlassIcon } from "@phosphor-icons/react";

export default function Example() {
  return (
    <InputGroup>
      <InputGroup.Addon>
        <MagnifyingGlassIcon />
      </InputGroup.Addon>
      <InputGroup.Input placeholder="Search..." aria-label="Search" />
    </InputGroup>
  );
}
```

## API 参考

### `InputGroup`

<p>
  根容器，为所有子组件提供上下文。接受 Field 属性（`label`、`description`、
  `error`），当提供 label 时会将内容包裹在 Field 中。
</p>
<PropsTable component="InputGroup" />

### `InputGroup.Input`

<p>
  文本输入元素。从 InputGroup 上下文继承 `size`、`disabled` 和 `error`。
  接受所有标准 input 属性，但与 Field 相关的属性由父级处理。
</p>
<PropsTable component="InputGroup.Input" />

### `InputGroup.Addon`

<p>
  放置在输入框开头或末尾的容器，用于承载图标、文本或紧凑按钮。
</p>
<PropsTable component="InputGroup.Addon" />

### `InputGroup.Button`

<p>
  用于辅助操作的按钮，如切换、复制或帮助。渲染在 Addon 内。
  传入 `tooltip` 属性可在悬停时显示提示。
</p>
<PropsTable component="InputGroup.Button" />

### `InputGroup.Suffix`

<p>
  紧接输入文本的内联文本（例如 `.workers.dev`）。输入框宽度会随用户输入自动调整。
</p>
<PropsTable component="InputGroup.Suffix" />

## 无障碍

  <div class="space-y-4 text-sm">
    <div>

      ### 标签要求

      <p>
        InputGroup 需要满足以下任一方式提供可访问名称：
      </p>
      <ul class="mt-2 ml-4 list-disc space-y-1">
        <li>
          在 InputGroup 上使用 `label` 属性（渲染可见标签，并带有内置
          Field 支持）
        </li>
        <li>
          对于没有可见标签的输入框，在 InputGroup.Input 上使用 `aria-label`
        </li>
        <li>
          在 InputGroup.Input 上使用 `aria-labelledby` 进行自定义标签关联
        </li>
      </ul>
      <p class="mt-2">
        开发环境下，缺少可访问名称会触发控制台警告。
      </p>
    </div>
    <div>

      ### 组角色

      <p>
        InputGroup 会自动以 `role="group"` 渲染，从而在语义上为辅助技术
        将输入框与其 addons 关联起来。
      </p>
    </div>

  </div>
