## 用法

使用 `value` 配合 `onValueChange` 控制标签；非受控用法则使用 `defaultValue`。

```tsx
const [tags, setTags] = useState<string[]>([]);

<TagInput
  label="Labels"
  value={tags}
  onValueChange={setTags}
  placeholder="Add a label"
/>
```

### 表单
设置 `name`，即可将每个标签作为独立的表单值提交，使 `FormData.getAll(name)` 返回所有标签。当焦点离开输入框时，仍留在输入框中的文本会转为一个标签，因此点击提交按钮时也会包含它。只要至少有一个标签，`required` 即可通过校验。
<ComponentExample demo="TagInputFormDemo"><TagInputFormDemo client:load /></ComponentExample>

### 只读
`readOnly` 会显示标签并保持输入框可聚焦，但无法添加或移除标签。与原生只读输入框一样，即使设置了 `required`，它也会被表单校验跳过。

## 行为

按 Enter、逗号或 Tab 即可创建标签。失焦时也会提交当前值。粘贴以逗号或换行分隔的文本时，会将其插入到光标处的当前文本中，然后同步创建每个值。粘贴不含分隔符的文本时，行为与普通粘贴相同。重复值会被忽略。

## 本地化

通过 `labels` 可以翻译 TagInput 生成的所有文本：回退输入名称、标签移除操作、无效值提示和达到最大数量提示。

```tsx
<TagInput
  label="Etiquetas"
  labels={{
    input: "Agregar etiqueta",
    removeValue: (value) => `Eliminar ${value}`,
    invalidValue: (value) => `${value} no es valido.`,
    maxValuesReached: (maxValues) => `Maximo de ${maxValues} etiquetas.`,
  }}
/>
```
