## 用法

```tsx
import { Tooltip, Button } from "@cloudflare/kumo";

export default function Example() {
  return (
    <Tooltip content="Tooltip text" render={<Button />}>
      Hover me
    </Tooltip>
  );
}
```

如需在多个 tooltip 之间统一延迟分组，请参阅 [TooltipProvider](#tooltipprovider)。

## TooltipProvider

<p>
  `TooltipProvider` 将多个 tooltip 分组，使第一个 tooltip 显示后，切换到
  其他 tooltip 时会跳过打开延迟。将它放在应用根节点或布局中一次即可；
  不要在每个 `Tooltip` 外面分别包裹。
</p>

```tsx
// Wrap your app or layout once
<TooltipProvider>
  <App />
</TooltipProvider>

// Then use Tooltip anywhere inside
<Tooltip content="Add" render={<Button shape="square" icon={PlusIcon} />} />
```
