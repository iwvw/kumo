## 用法

```tsx
import { Select } from "@cloudflare/kumo";

export default function Example() {
  const [value, setValue] = useState("apple");

  return (
    <Select
      label="Favorite Fruit"
      value={value}
      onValueChange={(v) => setValue(v ?? "apple")}
      items={{ apple: "Apple", banana: "Banana", cherry: "Cherry" }}
    />
  );
}
```

### 占位符

<p>
  使用 `placeholder` 属性，在未选择任何值时显示文字。使用 `renderValue`
  自定义选中值的显示时，当值为 `null` 会显示占位符，
  而不会调用 `renderValue`。
</p>

```tsx

  placeholder="Select a user..."
  value={user}
  renderValue={(user) => user.name} // Only called when user is not null
/>
```

### 自定义渲染

<p>
  使用 `renderValue` 自定义选中值在触发器按钮中的外观。当处理复杂的
  对象数据结构，而不只是简单字符串值时，
  这一用法很有用。
</p>

<ComponentExample demo="SelectCustomRenderingDemo">
  <SelectCustomRenderingDemo client:load />
</ComponentExample>

<p>
  只有在选中值后才会调用 `renderValue` 函数。使用 `placeholder`
  定义未选择任何值时的显示内容。
</p>

<p>
  Select 会拿值与 items 比较，以确定哪个选项被选中。
  对于对象类型的选项，默认按引用比较，而不是按值比较。
  如果希望按值比较对象选项，可以使用
  `isItemEqualToValue` 属性。
</p>

```tsx
<Select
  className="w-[200px]"
  placeholder="Select a language..."
  renderValue={(v) => (
    <span>
      {v.emoji} {v.label}
    </span>
  )}
  value={value}
  onValueChange={(v) => setValue(v)}
  // Provides custom comparison logic
  isItemEqualToValue={(item, value) => item.value === value.value}
>
  {languages.map((language) => (
    <Select.Option key={language.value} value={language}>
      {language.emoji} {language.label}
    </Select.Option>
  ))}
</Select>
```

### 多选

<p>
  使用 `multiple` 属性启用多选。此时值变为选中项的数组。
  使用 `placeholder` 定义空状态，使用 `renderValue`
  自定义选中项如何显示。
</p>

```tsx
<Select
  multiple
  placeholder="Select columns..."
  value={selectedColumns}
  renderValue={(columns) => columns.join(", ")}
  onValueChange={setSelectedColumns}
>
  <Select.Option value="name">Name</Select.Option>
  <Select.Option value="email">Email</Select.Option>
</Select>
```
