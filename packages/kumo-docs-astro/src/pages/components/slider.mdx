## 用法

```tsx
import { Slider } from "@cloudflare/kumo";

export default function Example() {
  return <Slider label="Volume" defaultValue={40} />;
}
```

`Slider` 基于 [Base UI 的 Slider](https://base-ui.com/react/components/slider) 构建。`value`、`defaultValue`、`min`、`max`、`step`、`format` 和 `onValueChange` 等属性会传递给底层组件。

## 无障碍

- 每个滑块都是原生 range 输入，因此默认支持方向键、<kbd>Page Up</kbd>/<kbd>Page Down</kbd> 以及 <kbd>Home</kbd>/<kbd>End</kbd>。
- `label` 为滑块及其滑标提供名称。没有可见标签时，请传入 `getAriaLabel`。
- 数值徽章和范围标签对辅助技术隐藏，因为每个滑块已经会宣告其格式化后的数值。
