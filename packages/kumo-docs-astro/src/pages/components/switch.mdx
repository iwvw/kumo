## 用法

```tsx
import { Switch } from "@cloudflare/kumo";
import { useState } from "react";

export default function Example() {
  const [checked, setChecked] = useState(false);

  return (
    <Switch checked={checked} onCheckedChange={(val) => setChecked(val)} />
  );
}
```

### 变体

<p>
  Switch 支持两种变体：`default`（开启时为蓝色）和 `neutral`（单色）。
  两者都采用 squircle 形状。
</p>

  <SwitchVariantsDemo client:visible />
</ComponentExample>

### 中性变体

<p>
  中性变体采用单色配色和 squircle 形状，适合
  低调、不显眼的开关。
</p>

  <SwitchNeutralDemo client:visible />

### 自定义 ID

<p>
  提供自定义 `id` 时，点击标签仍会切换开关。`id` 会转发给 Base UI，
  使标签的 `htmlFor` 与之保持同步。
</p>
<ComponentExample demo="SwitchCustomIdDemo">
  <SwitchCustomIdDemo client:visible />
</ComponentExample>

### 开关组

<p>
  使用 `Switch.Group` 将相关开关组合在一起。为整个组提供共用的图例、
  描述和错误提示。
</p>
<ComponentExample demo="SwitchGroupDemo">
  <SwitchGroupDemo client:visible />
</ComponentExample>

### 视觉隐藏的图例

<p>
  使用带 `className="sr-only"` 的 `Switch.Legend`，可以在视觉上隐藏图例的同时
  保持其为屏幕阅读器可读。当组已由父级 `Field` 或标题提供了标签，
  再显示图例会形成冗余标签时，
  这一用法很有用。
</p>
<ComponentExample demo="SwitchLegendSrOnlyDemo">
  <SwitchLegendSrOnlyDemo client:visible />
</ComponentExample>

### 自定义图例样式

<p>
  `Switch.Legend` 接受 `className`，可完全控制图例的呈现方式。当你需要
  自定义排版、颜色或布局时，请用它替代
  `legend` 字符串属性。
</p>
