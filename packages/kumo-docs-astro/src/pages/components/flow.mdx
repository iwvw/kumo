## 用法

  <p>
    Flow 组件协同工作，可创建有向流程图。使用
    `Flow` 作为容器，
    `Flow.Node` 表示各个
    步骤，使用
    `Flow.Parallel` 创建
    分支路径。
  </p>

```tsx
import { Flow } from "@cloudflare/kumo";

export default function Example() {
  return (
    <Flow>
      <Flow.Node>Step 1</Flow.Node>
      <Flow.Node>Step 2</Flow.Node>
      <Flow.Node>Step 3</Flow.Node>
    </Flow>
  );
}
```

### 自定义锚点

<p>
  默认情况下，连接器连接到每个节点的中心。使用 `Flow.Anchor`
  及其 `render` 属性可以指定自定义连接点。`type` 属性
  控制锚点是作为 `"start"` 点（连接器离开处）还是
  `"end"` 点（连接器到达处）。
</p>
