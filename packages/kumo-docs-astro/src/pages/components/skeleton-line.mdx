## 块高度

  <p class="mb-4">
    使用 <code>blockHeight</code> 设置容器的高度，
    该容器会在垂直方向上居中骨架线。在替换已知行高的文本时很有用。
    接受数字（视为 <code>px</code>）或任意 CSS
    字符串值。
  </p>
  <ComponentExample demo="SkeletonLineBlockHeightDemo">
    <SkeletonLineBlockHeightDemo client:visible />
  </ComponentExample>
