## 用法

### 使用内置 Field（推荐）

<p>
  使用 `label` 属性启用内置 Field 包装器，支持标签、描述和错误提示。
</p>

```tsx
import { InputArea } from "@cloudflare/kumo";

export default function Example() {
  return (
    <InputArea
      label="Description"
      placeholder="Enter a description..."
      description="Provide details about your project"
    />
  );
}
```

### 裸 InputArea（自定义布局）

<p>
  对于自定义表单布局，可在不带 `label` 的情况下使用 InputArea，但必须提供
  `aria-label` 或 `aria-labelledby` 以保证无障碍访问。
</p>

```tsx
import { InputArea } from "@cloudflare/kumo";

export default function Example() {
  return <InputArea placeholder="Add notes..." aria-label="Notes" rows={3} />;
}
```

## 无障碍

### 标签要求

<p>InputArea 需要满足以下任一方式提供可访问名称：</p>

<ul class="ml-4 list-disc space-y-1">
  <li>`label` 属性（推荐）</li>
  <li>对于裸文本区域，使用 `placeholder` + `aria-label`</li>
  <li>使用 `aria-labelledby` 进行自定义标签关联</li>
</ul>

<p class="mt-2">
  开发环境下，缺少可访问名称会触发控制台警告。
</p>

### 错误关联

<p>
  错误信息会通过 ARIA 属性自动关联到文本区域，供屏幕阅读器播报。
</p>
